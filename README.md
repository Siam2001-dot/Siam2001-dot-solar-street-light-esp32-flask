# Smart Solar Street Light System

ESP32 + LDR sensor based automatic street light with Flask monitoring backend.

## Folders
- `esp32-code/` — Arduino code for ESP32 (light sensing & control)
- `flask-server/` — Python Flask backend for logging/monitoring
